# ChatGPT subscription (experimental)

Install the plugin-only ZIP by extracting its `xray.koplugin` directory into `.adds/koreader/plugins/` on the reader, so the installed path is `.adds/koreader/plugins/xray.koplugin/`. Back up the existing plugin directory first. When merging an update into an existing installation, **preserve `.adds/koreader/plugins/xray.koplugin/xray_config.lua`** and do not overwrite it with the ZIP copy: it holds existing X-Ray settings and API configuration. Preserve your other KOReader settings too, then restart KOReader. Open **X-Ray → API Keys & Providers → ChatGPT subscription (experimental) - account**. The existing **OpenAI ChatGPT** entry remains the API-key route, billed separately. Sign in first, then explicitly choose **ChatGPT subscription (experimental) → gpt-6-luna, gpt-6-sol, or gpt-6-astra** under Primary AI Model. Luna remains the default subscription model. No default model is changed during installation or login. Selecting the subscription model as primary never silently falls back to a paid API secondary.

This path requires a KOReader runtime with compatible LuaSec HTTPS support and a trusted CA certificate bundle for certificate and hostname verification. The transport tries the operating system's trust stores first, then the plugin's bundled public curl/Mozilla CA snapshot at `xray.koplugin/certs/ca-bundle.crt` as a fallback (see its bundled license and provenance). If verified TLS cannot be established, authentication and subscription requests must fail closed. Do not disable certificate checks as a workaround. The bundled CA file does not establish on-device compatibility: TLS behavior and actual OAuth acceptance still require separate verification on the target reader with a user-approved login.

On the reader, accept the experimental warning and follow the displayed `https://auth.openai.com/...` verification URL or its QR code on your phone. Enter the displayed device code on OpenAI's page and approve there. X-Ray never asks for your password or routes OAuth tokens through its phone/PC API-key setup relay. Cancel the reader dialog to stop polling. Device-code login is beta and may need enabling in your ChatGPT security settings or by your workspace administrator. Use the separate account entry to reconnect or sign out.

**Limitations and security:** This uses observed, undocumented subscription service interfaces, not a guaranteed official third-party API integration or OpenAI endorsement. Sign-in status only indicates locally stored credentials, not account entitlement, available model access, or remaining quota. Subscription allowance is limited and may be shared with other Codex/ChatGPT usage. No OAuth acceptance or authenticated model request has been verified for this plugin until a user explicitly completes a fresh login on the target device. Tokens are stored separately under KOReader's settings directory at `xray/openai_auth.json`, not in the API-key settings or backup. Reader storage, especially USB-accessible VFAT, does not offer meaningful per-file secrecy: someone with physical access may copy a session. Sign out clears this local token store; it does not guarantee server-side token revocation. Do not copy it to another device or share diagnostics containing it. English fallback strings in the experimental account flow are not yet translated.
